# ペナントラボ Ver.9.2

架空12球団で143試合のペナントレースを戦い、CS・日本シリーズ・ドラフトを複数年プレイできるWebゲームです。PC・スマートフォンに対応します。

## 今回の変更：選手名のバリエーションを大幅増加

* 初期編成・新規ドラフト候補（120名）・補強市場（年2名）・COM球団の選手など、すべての新規生成選手に適用します。
* 日本人選手の「姓」と「名」を大幅拡充。組み合わせで数万通り以上の名前を生成できます。
* 一度生成した氏名を保存することで、今後生成する選手と既存選手との同姓同名を防ぎます。旧バージョンから引き継いだ選手同士にもともとある重複は変更せず、そのまま維持します。
* 既存選手の名前、ドラフト獲得済み選手の名前、過去の成績や受賞歴は変更しません。新しく生成する新人から反映します。
* Ver.9.1までのセーブキー `penanto_lab_save_v1` は変更していません。新ゲームで遊ぶ場合はゲーム内「最初から」を選択してください（現在のセーブが消えるので必ずバックアップしてください）。

## ゲームの起動と更新

1. ZIPを解凍して `index.html` をChrome、Edge、Safariなどのブラウザで開いてください。
2. GitHub Pagesで公開している場合はリポジトリの `index.html` だけを新しいファイルに置き換えます。
3. ChatGPT内のファイルビューアーではJavaScriptゲームが動作しないことがあります。通常のブラウザかGitHub Pagesで遊んでください。

## 継続機能

12球団・143試合、調子、起用ロック、CS・日本シリーズ、タイトル表彰、ドラフト競合抽選と外れ1位の確定済み指名者除外、上部の進行ボタンなどVer.9.1の仕様を引き継ぎます。
